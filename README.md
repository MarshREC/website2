# Live Discord Profile

A token-free static profile page for GitHub Pages. It retrieves public presence data from the Lanyard API for Discord user `1370490512552890368` directly in the visitor's browser.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In the repository settings, open **Pages** and deploy from the `main` branch / root folder.

No build step, server, or Discord account token is required.

## What it includes

- Live Discord avatar, display name, username, presence, and custom status
- Active game/app plus elapsed time when supplied by Lanyard
- Spotify song, album artwork, artist, and live progress when available
- Automatic 30-second refresh, a manual refresh button, cached fallback, and offline states
- Original moonlit backdrop, animated stars, film grain, aurora haze, parallax, and reduced-motion support
